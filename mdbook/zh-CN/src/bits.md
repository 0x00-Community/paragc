# 比特布局

paragc 和 j8 放进内存的每个字，逐位说明。

## 私有对象

一个对象由 24 字节的头、数据和可选的尾巴组成，总长向上取整到 8 字节：
`(HEADER + size_of::<T>() + tail).next_multiple_of(8)`。

```text
偏移 0   mark   u32   bit 0–29  最后一次标记的纪元（0 = 年轻；上限 MAX_EPOCH = 2^30 − 1）
                      bit 30    BUSY：某个回收线程认领了它，正在复制
                      bit 31    FORWARDED：已搬走，新地址在 drop 字里
偏移 4   info   u32   bit 0–23  粒数，含头（× 8 字节；最大 128 MiB）
                      bit 24–29 引用计数（到 63 粘住）
                      bit 30    计数奇偶位（这份计数属于哪一代）
                      bit 31    大对象
偏移 8   visit  fn    追踪、改写，或回答类型询问（见「标记」）
偏移 16  drop   fn?   析构函数或空；搬走之后存转发地址
偏移 24  数据 T，然后是尾巴
```

`mark` 和 `info` 合起来叫 `Core`，块、行、清扫只看这一部分。

## 跨堆对象

头是 16 字节，不存代码指针：

```text
偏移 0   mark   u32   同上
偏移 4   info   u32   同上（所以块的代码是共用的）
偏移 8   ty     u32   在堆的类型表里的编号；回收按这个类型的指针图走
偏移 12  stamp  u32   出生戳：堆化身号与分配纪元经 SplitMix64 混合
偏移 16  数据
```

私有对象晋升时，24 字节的头换成 16 字节的头，数据和尾巴原样拷过去。

## 块的元数据

每个 32 KiB 的块：

| 表 | 大小 | 含义 |
| --- | --- | --- |
| 行标记 | 128 × `u32` = 512 B | 每 256 字节一行一个纪元；比上一次完成的纪元旧就是空闲行 |
| 起点位图 | 4096 位 = 512 B | 每 8 字节一个粒一位，在每个对象的第一个粒置位 |

## 边与字

| 东西 | 布局 |
| --- | --- |
| `Gc<'gc, T>` | 一个指针，指向数据（头之后） |
| `Slot<'gc, T>` | 两个字：当前值，以及引用计数上次计数时的值 |
| `WordSlot<'gc>` | 两个字。值 ≥ `WORD_POINTER_MIN`（`0xFFF8 << 48`）时是指针：高 16 位是用户的标签（搬动时保留），低 48 位是数据地址。其余的字是普通数据 |
| `CrossHeapSlot` | 一个 `u64`：相对跨堆地址区起点的偏移，每个进程都一样 |
| `CrossHeapWeak` | 一个 `u64`：高 37 位是偏移 ÷ 8（1 TiB 地址区要 40 位，对齐省掉 3 位），低 27 位是出生戳 |
| `Signature` | 32 字节：弱引用字（8）、堆化身号（8）、类型键（16） |

## j8 的 JS 值

JS 的 `Value` 是一个 64 位字，NaN-boxing 编码：

- double 原样存放（NaN 统一成 `0x7FF8_0000_0000_0000`）；
- 其余的值都是 `0xFFF0 << 48 | (tag + 1) << 48 | 载荷`。

| 高 16 位 | 种类 | 载荷 |
| --- | --- | --- |
| `0xFFF1` | undefined | – |
| `0xFFF2` | null | – |
| `0xFFF3` | 布尔 | 0 或 1 |
| `0xFFF5` | 未初始化的绑定（TDZ） | – |
| `0xFFF6` | 惰性值 | 编号 |
| `0xFFF8` | 字符串 | `JsStr` 的地址 |
| `0xFFF9` | symbol | 地址 |
| `0xFFFA` | bigint | 地址 |
| `0xFFFB` | 对象 | `Object` 的地址 |
| `0xFFFC` | 访问器对 | 地址 |
| `0xFFFD` | 上下文（闭包环境） | 地址 |

所有指向堆的种类，高 16 位都 ≥ `0xFFF8`，正好是 `WordSlot` 当作指针的范围。所以存在 `WordSlot`（j8 的 `ValueCell`）里的
JS 值就是一条边：回收器追踪它、给它计数、搬动时改写它，标签原样保留。

## 例子：一个 JS 字符串

`JsStr` 是 32 字节的字段，文本放在后面的尾巴里：

```text
私有头    24 B
JsStr     32 B  buf    8  空：文本在我自己的尾巴里；非空：是另一个字符串缓冲区的视图
                len    4  UTF-8 字节数
                units  4  UTF-16 码元数（恰好在纯 ASCII 时等于 len）
                start  4  在缓冲区里的起点（视图用）
                cap    4  尾巴里 UTF-8 的容量（留给续写的空间）
                used   4  缓冲区已被认领的字节数（原子；续写用 CAS 认领）
                填充   4
尾巴     cap B  UTF-8；非 ASCII 时再对齐到 2，接 units 个 u16 的 UTF-16
```

一个 40 字节的 ASCII 字符串是 24 + 32 + 40 = 96 字节 = 12 个粒，`info` 的低 24 位写 12。晋升进跨堆后，同一个字符串是
16 + 32 + 40 = 88 字节。
