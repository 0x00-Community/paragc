# 前言

这本书讲 [paragc](https://github.com/0x00-Community/paragc) 怎么工作：从第一次 `alloc`，一直到几个进程共用的一个堆。
写给两类读者：

- **使用者**：把 paragc 嵌进 Rust 程序（例如 [j8](https://j8.app238.com) 这样的语言运行时、数据库、图库），想知道每个
  接口承诺什么、要付出什么代价。
- **贡献者**：想改回收器，需要知道撑起它的那些不变量。

paragc 是一个追踪式垃圾回收器，堆采用 Immix 式的标记-区域布局。多个线程同时分配，回收时在每个核上并行标记和清扫，整个
回收器里没有一把锁。在 Linux 上，`crossheap` feature 增加了放在共享内存里的堆：别的进程可以映射它，读写里面的对象，
并凭签名找到对象。

## 怎么读

| 部分 | 内容 |
| --- | --- |
| 入门 | paragc 是什么、第一个程序、各种句柄以及它们为什么带品牌 |
| 私有堆 | 进程内的堆：布局、分配、标记、清扫、并发工作、疏散、年轻回收、引用计数、弱引用 |
| 堆之间 | 一个私有堆直接指向另一个私有堆，以及回收跨堆的环 |
| 跨堆 | 共享内存上的堆：地址空间、文件布局、不带代码的对象、随时可能死掉的进程、跨进程的弱引用与签名、把私有对象晋升进跨堆 |
| 质量与路线 | 测试、Miri、性能对比、代码规矩、已知限制、接下来做什么 |

每一页写的都是 `main` 上代码当前的行为。书和代码不一致时以代码为准，欢迎提 issue，或者用页面顶部的编辑链接直接改。
