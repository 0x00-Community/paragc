# 术语表

| 术语 | 含义 |
| --- | --- |
| 块（block） | 32 KiB、按大小对齐的堆内存单位 |
| 行（line） | 块内 256 B 的复用单位 |
| 粒（granule） | 8 B，分配对齐 |
| 纪元（epoch） | 回收写进标记字和行标记的编号；从不清零 |
| mutate | `Heap::mutate`，线程在其中可以分配、使用 `Gc` 句柄的一次调用 |
| 品牌（brand） | 把 `Gc` 绑在一次 `mutate` 上的 `'gc` 生命周期；也指把它映射回来的 `brand!` 类型 |
| 根（root） | `Root<B>`，不带生命周期、让对象存活的句柄 |
| 入口（entry） | 为来自堆外的引用（`Far`、跨堆入口）领的根表槽 |
| handle | `Handle<'gc, T>`，指向 handle 表某一项的引用；对象搬家只改写表项，handle 本身不变 |
| tlab | 线程本地分配缓冲 |
| 溢出游标 | 放不进当前这段的中等对象用的第二个分配游标 |
| 黑分配 | 并发标记期间新对象直接拿到标记纪元 |
| SATB | 开始时快照：并发标记期间写屏障标记被覆盖的旧值 |
| 疏散（evacuation） | 标记时把活对象从稀疏块里复制出去 |
| 转发地址 | 搬动后留在旧头里的新地址 |
| 年轻 / 老 | 还没有 / 已经带上上一次完成的纪元（粘性标记位） |
| 记忆集 | 被写入年轻值的老对象槽 |
| 晋升（promotion） | 年轻对象变老：原地、搬动，或搬进挂接的跨堆 |
| RC | 来自老对象的边的引用计数 |
| 奇偶位 | 区分本代计数和上一代计数的位 |
| `Far` | 一个私有堆直接指向另一个私有堆的引用 |
| 一起回收（group collection） | 把几个堆放在一起回收，收掉跨堆的环 |
| 跨堆（cross-heap） | 放在共享内存文件里、多个进程可用的堆 |
| 地址区 / 窗口 | 为跨堆保留的地址范围 / 其中一个堆的 16 GiB |
| 固定地址区 | 位于 64 TiB、每个进程地址都相同的地址区 |
| 超级块 | 跨堆的第一页 |
| 挂接（attachment） | 进程在跨堆超级块里的槽 |
| 化身号（incarnation） | 跨堆建立时得到的随机身份 |
| 出生戳 | 跨堆对象头里由化身号和分配纪元得出的 32 位标签 |
| 类型键 | 可共享类型的名字、大小与指针图的哈希 |
| 指针图 | 可共享类型各指针字段的偏移 |
| 签名 | 32 字节（弱引用字、化身号、类型键），让别的进程认出一个跨堆对象 |
| 只归主人回收 | 只能由主人回收的跨堆（挂接的老年代） |
| 信箱 | 超级块里的一个栈，别的进程把对象投进来请主人代办 |
