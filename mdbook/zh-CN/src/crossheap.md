# 跨堆概览

**跨堆**（`CrossHeap`）是放在共享内存文件里的堆。凡是能打开这个文件的进程，都能映射它并使用：分配、读、写、回收。

```toml
[dependencies]
paragc = { version = "0.6", features = ["crossheap"] }
```

这个 feature 只在 **Linux** 上存在。在 macOS 和 Windows 上它什么都不编，只有私有堆。feature 打开且目标是 Linux 时，
`build.rs` 输出 `cfg(crossheap)`，所有跨堆的条目都挂在这个 cfg 上。

## 两种堆，两个共享范围

| | 线程之间共享 | 进程之间共享 |
| --- | --- | --- |
| 私有堆（`Heap`） | ✓ | ✗ |
| 跨堆（`CrossHeap`） | ✓ | ✓，能打开文件的进程都可以 |

| 从 → 到 | 私有堆 | 跨堆 |
| --- | --- | --- |
| 私有堆 | ✓ 直接指针（堆之间用 `Far`） | ✓ `CrossHeapGlobal`，晋升后是绝对地址 |
| 跨堆 | ✗（别的进程看不到私有内存） | ✓ `CrossHeapSlot`、`CrossHeapRef`、`CrossHeapWeak` |

跨堆里没有东西指向私有堆，所以私有堆和跨堆之间不会成环。

## 信任

映射了一个堆的进程可以读它的全部内容，也可以把它写坏。共用一个堆的进程彼此信任，权限检查就是文件权限。不过，来自不可信
一方的签名只会被读取，伪造的签名不会让读的一方崩溃。

## 背后的目标

不同进程里的 j8 运行时之间零拷贝地交换 JS 值。一个进程发出 32 字节的签名；接收方，或者 dowin 这样的中转方，映射发送方的
堆，找到对象读取它，或者把签名继续转发出去。
