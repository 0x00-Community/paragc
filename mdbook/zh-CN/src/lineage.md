# 从它们到 paragc

paragc 由前几章里的想法拼成，再加上一个只有 Rust 才做得到的想法。本页把 paragc 的每一部分对应到它的来源；后面的章节逐一详细
展开。

## paragc 借了什么

| 想法 | 来源 | 在 paragc 里 |
| --- | --- | --- |
| 从根出发追踪 | McCarthy，1960 | 每次回收都从 `ScopeGlobal`、入口和记下的槽出发标记 |
| 三色标记、SATB 屏障 | Dijkstra 等 1978；Yuasa 1990 | 并发标记，`Slot` 写入上的删除屏障加黑分配（[并发](concurrent.md)） |
| 线程本地缓冲里递增分配 | 复制式收集器；JVM 的 TLAB | `Tlab`，`scope` 里每线程一个（[分配](allocation.md)） |
| 标记-区域堆：块和行 | Immix，2008 | 32 KiB 块、256 B 行、溢出分配（[布局](layout.md)） |
| 机会式疏散 | Immix | 标记时复制稀疏块（[疏散](evacuation.md)） |
| 分代、记忆集 | Lieberman 与 Hewitt；Ungar | 粘性标记位的年轻回收、记录槽（[年轻回收](young.md)） |
| 工作窃取的并行标记 | Endo、Flood 等；JVM 的 Parallel 与 G1 | 每个工人一个 crossbeam 队列（[标记](marking.md)） |
| 老对象引用计数、后台释放 | Collins 1960；LXR 2022 | 6 位计数在年轻回收时结算，减法在线程池上做（[引用计数](refcount.md)） |
| 弱引用 | Lisp 的弱指针；Java 的 `WeakReference` | `Weak`，每次停顿时清理（[弱引用](weak.md)） |
| 作为库供宿主语言使用的收集器 | Boehm GC、cppgc | 一个 Rust crate；j8 在它上面建 JS 堆 |

## paragc 添了什么

**借用检查器就是全停。** JVM 需要安全点和栈图，cppgc 需要保守扫栈。paragc 两样都不需要：

- `ScopeLocal<'heap, 'scope, T>` 是对产生它的 scope 的借用，所以不会有没登记的指针活得比它久；
- 全停回收要 `&mut` 堆或某个独占 scope，所以编译器证明回收时没有活着的直接指针。

正因如此，paragc 作为一个普通的库，就能**搬**对象（疏散、年轻复制），既不需要读屏障，也不需要保守式钉住。

**任何地方都没有锁。** 多个 mutator 同时从一个堆分配。块、根、弱引用、工作队列都是无锁结构，线程池用一个原子字唤醒。

**放在共享内存里、跨进程的堆。** 前几章里没有哪个收集器让几个进程同时用一个堆。paragc 的跨堆做到了：

- 对象里没有代码指针，回收按指针图走；
- 偏移在每个进程里含义相同；
- 进程死在回收中途也能恢复；
- 弱引用和签名不会让一个进程去等另一个进程；
- 私有堆的存活者可以晋升进跨堆。
