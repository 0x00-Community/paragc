# 跨堆引用与生命周期隔离（设计稿）

## 1. 两种堆 × 两个层级

| | 进程内共享（多线程） | 跨进程共享 |
| --- | --- | --- |
| **私有堆**（进程内存） | ✓ | ✗ |
| **公开堆**（共享内存文件） | ✓ | ✓ 能打开那个共享内存文件就能用 |

- **私有堆**：现在的 paragc `Heap`。对象是任意 `Trace`，可以有 `Drop` / `Vec`；头里存函数指针；内部队列用 crossbeam。
- **公开堆**：共享内存文件上的堆。权限就是文件权限——打不开文件就映射不了、拿不到它的 mutator，也就碰不到里面的对象。
- 主进程负责引擎存活，持有公开堆文件，做公开堆的回收。

## 2. 引用规则：零拷贝，直接拿

互相引用的目的就是零拷贝：跨堆的边是**直接指针**，不复制、不经过间接表。

| 从 → 到 | 私有堆 | 公开堆 |
| --- | --- | --- |
| **私有堆** | ✓ 同进程，直接指针 | ✓ 直接指针 |
| **公开堆** | ✗ | ✓ 直接指针 |

- **公开 → 私有禁止**：公开对象会被别的进程读到，那边没有这块私有内存。于是私有堆与公开堆之间不会成环。
- **解引用要目标堆的 mutator**：`far.get(&mb)`。手里有 `mb` 证明两件事：本进程打开了那个堆（有权限），
  而且此刻在它的 mutate 里（它的清扫 / 疏散不会把对象从脚下拿走）。运行时只比一次「指针里的堆号 = mb 的堆号」，
  对不上是用错了堆，按程序错误 panic。
- 一个线程可以同时在几个堆的 mutate 里，各自的品牌并存；类型系统保证一个堆的 `Gc` 只能经跨堆字段放进别的堆。

### 字段类型

| 类型 | 放在哪 | 指向 | 存的是 |
| --- | --- | --- | --- |
| `Slot<'gc, T>` | 任意堆 | 同一个堆 | 私有堆：绝对地址（现状）；公开堆：公开偏移 |
| `Far<'a, B>` | 私有堆（品牌 `'a` = 持有方堆） | 同进程的另一个私有堆 | 目标堆根表 + 槽号 + 绝对地址（建好后不变） |
| `Public<T>` | 私有堆或公开堆 | 某个公开堆 | 公开偏移（u64，高位即堆号） |

## 3. 公开堆的地址与布局

- 每个进程保留一块**公开地址区**：大小、对齐全都一样，按堆号切成固定大小的窗口。
  公开堆 *k* 永远映射在第 *k* 个窗口；进程只映射它打开了的堆。
- 公开指针 = 相对公开地址区起点的 u64 偏移，同一个值在所有进程里指向同一个对象（跨公开堆也一样）。
  起点从区内任意地址抹低位得到。
- 堆号由主进程在建堆时分配，记在注册表里。

### 从 0 开始

- **建堆时文件长度是 0**，一页都不占。用到哪里才把文件延长到哪里；没写过的地方是空洞，不占内存。
- 保留窗口只是占住一段**地址**（`PROT_NONE` + `MAP_NORESERVE`），不是内存。本机实测：保留 32 GiB 后
  VmRSS 不变（1352 ⇒ 1420 kB，误差内）、系统 Committed_AS 不变；文件延长到 64 MiB、只写首尾两页，实际占用 8 KiB。
- 进程进 mutate 时比一下超级块里的当前长度，不够就补映射（一次比较，平时不走系统调用）。

### 窗口内的布局：位置全部定死

```
窗口偏移
0                超级块（1 页）：当前长度、类型表、挂接表、各队列的头
入口表起点        入口表：位置固定，从 0 项开始往后长，容量上限是常量
块区起点          块：从这里往后按需领
```

- 任何进程、任何堆，入口表都在「窗口起点 + 固定偏移」，不用查任何指针就能找到。
- 入口表本身也只有这一张，不分段：每项 `{目标对象偏移, 来源号}`，原子游标追加；整理由这个堆的回收在停顿里做。
- 入口表与块区之间没用到的部分是文件空洞，不占内存。

## 4. 公开堆的对象

- 头 16 B：`type: u32`（类型号；搬走后改存转发偏移）、`mark: u32`、`info: u32`、填充。不存函数指针。
- `#[derive(Trace)]` 额外生成**指针图**（每个 `Slot` / `Public` 字段的偏移，数组按步长重复）；类型表放在超级块里：
  `类型键（类型路径 + 布局哈希） → 类型号 + 指针图`。回收照指针图走，回收方不需要链接用户的类型。
- 类型限制（`Shared` trait，derive 检查）：`#[repr(C)]`，字段只有纯数据、`Slot`、`Public`、堆内数组；不许 `Drop`。

## 5. 回收：每个堆独立，入口表当根

统一一条规则：**从堆外指进堆 H 的引用，登记在 H 的入口表里。**

- 来源那边维护登记：写屏障把跨堆指针写进字段时追加一条；来源堆回收时重算，删掉不再引用的。
- H 回收时入口表里的对象是根，而且**不搬**（别处的直接指针改不到）；其余对象照常疏散。
- 公开堆的入口表在窗口里的固定位置（见 3）；私有堆的入口表是堆结构里的固定字段。
  每项记着来源号（某个进程的私有堆，或另一个公开堆），来源没了，回收时把它的项全部丢掉。
- 于是每个堆单独回收，互不等待；回收公开堆不需要任何进程停下，也不需要读任何进程的私有内存。

### 跨堆的环

单独回收收不掉跨堆的环，按层级合并追踪：

- **私有堆之间**：本进程把有边相连的私有堆合成一组一起追踪。
- **公开堆之间**：主进程（能打开所有公开堆）把有边相连的公开堆合成一组一起追踪。
- 私有堆与公开堆之间不会成环（公开 → 私有禁止）。

## 6. 挂接与崩溃隔离（公开堆）

超级块里有挂接表，每个打开公开堆的进程占一项：`{pid, 在 mutate 里的线程数, 根段, 手里的分配块, 入口表登记段}`。

- 握手按挂接项计数，等待用共享页 futex。进程死了它那一项作废，不会卡住回收。
- 主进程用 pidfd 发现死亡：作废根段与登记段；它手里的块按刚交给分配缓冲的块处理（下次清扫照常扫）；
  正在并发标记就重来一轮，正在疏散就按转发地址补完（复制不改原对象，BUSY 的原样还在）。
- 公开堆文件在 tmpfs 上，主进程崩溃不丢堆；新主进程挂上来做同样的恢复后接着跑。

## 7. 现有机制在公开堆里

| 机制 | 变化 |
| --- | --- |
| 块 / 行 / 起点位图、并发标记、SATB、黑分配、年轻回收、引用计数、疏散 | 算法不变 |
| 灰队列、记忆集、计数登记、减量队列、可用块 | 换成超级块里登记头、节点在窗口里的无锁块链（手写，元素是公开偏移） |
| 根 | 按挂接项分段 |
| 回收线程 | 主进程的线程池；其他进程不起回收线程 |

## 9. P0 的实现

- 私有堆的入口表就是根表：每个根槽多记一个持有方堆号，普通 `Root` 记 0。单堆回收时入口就是根，年轻回收、
  引用计数（延迟计根）、并发标记（握手时照下）都沿用原逻辑。
- `Far` 建好后不变（指针与槽号两个字，改指向会撕裂）；要改就放在 `Slot` 后面的对象里换对象。
  `Far` 持有目标堆根表的 `Arc`：目标堆先析构，持有方之后析构 `Far` 还槽也安全；目标堆没了就拿不到它的 mutator，`get` 无从调用。
- 疏散前撤掉入口目标所在块的疏散标志（改当搬入目标），必须在任何工人开始标记之前。
- `collect_group`：组内持有的入口不当根；`Far` 的追踪把（目标堆根表, 目标头）报上来，按目标堆的纪元标灰，各堆轮流标到全空；
  组内持有、目标没标到的入口清空（持有方已死，等它被清扫前别让下一次回收碰已释放的对象）。不疏散。

## 10. P1 的实现

- 代码在 `src/public/`（只在 Linux 编译）：`region`（地址区保留与窗口映射）、`layout`（窗口内各段的固定偏移与表项结构）、
  `space`（`PublicSpace::create` / `create_anonymous` / `open`）、`heap`（分配、入口、类型登记、回收）、`mark`（按指针图并行标记）、`ptr`。
- 地址区 64 个窗口 × 16 GiB（1 TiB 地址，按 1 TiB 对齐）；Miri 下 4 × 16 MiB 的普通分配。窗口内：超级块 | 类型表（1024 项）|
  指针图（64K 个偏移）| 入口表（窗口每 16 KiB 一项）| 块状态表 | 块区。各段第一次用到时 `fallocate`，超级块里记着每段延长到哪。
- 头：两种堆共用 `Core`（标记字 + 信息字）放在最前面，私有堆的头是 `Core` + 追踪 / 析构函数（仍是 24 B），公开堆是 `Core` + 类型号（16 B）；
  块的清扫按 `Finalize` 区分（私有堆调析构，公开堆什么都不做）。
- `Public::index` + `PublicMutator::find`：入口号在每个映射里一样，`find` 先核对类型键再领自己的入口——这是另一个映射 / 进程拿到对象的办法（P2 要用）。
- 和原设计不同 / 还没做：公开堆只有暂停式回收（没有并发标记、年轻回收、引用计数、疏散）；大对象总是从块游标开新的一串块，死了拆成普通块，
  不复用成大块；建堆的句柄全部析构时删文件（P2 改成由主进程决定去留）；`PublicSlot` 是 8 字节，还没做私有堆那样的计数字。

## 11. 默认

- 公开堆的日常回收只由主进程做；其他进程只做 mutator。
